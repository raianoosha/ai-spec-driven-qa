# Login — deliberately incomplete product requirement

A user should be able to sign in with a username and password.

Invalid users should see a helpful error. Locked users must not get into the store.

After a successful sign-in, show the products page.

## Intentionally unresolved

- Which credentials and user states are valid?
- What does “helpful” mean, exactly?
- Are blank username and blank password different cases?
- What URL or page element proves that login succeeded?
- Are error messages required verbatim, or only semantically?
